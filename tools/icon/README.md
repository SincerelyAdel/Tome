# Tome icon

`tome-icon.svg` is the source. It is generated by `tome_icon.py` (palette
`teal`, seed 7): an open book painted in separate gold and teal brush strokes,
with a broken arc of sweeps over it, splatter, drips and three painted stars,
on white. It shares its brush style with the Scry icon.

    python tools/icon/tome_icon.py tools/icon/tome-icon.svg teal 7
    python tools/icon/render_icons.py <full path>/tools/icon/tome-icon.svg <full path to repo>

Pass full paths to `render_icons.py`: headless Chrome writes the screenshots
relative to its own folder otherwise. It writes every Android launcher size
(rounded white tile, transparent corners), and every iOS size too once the
project has an `ios/` folder.

Other partner colours are kept in `tome_icon.py` (`sapphire`, `crimson`,
`emerald`, `ink`), and a different seed gives a new arrangement of strokes.
The app's teal (`teal`, `tealLight` in `lib/theme.dart`) matches the icon.
